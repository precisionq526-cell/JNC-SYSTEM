The original-layout PDF text editor uses MuPDF.js 1.28.1, licensed under AGPL-3.0-or-later. Package and source: https://github.com/ArtifexSoftware/mupdf.js . The engine runs on the local shop server and preserves PDF page graphics while replacing selected text. Its license is included at vendor/licenses/MuPDF-AGPL-3.0.txt.

Earlier versions included SuperDoc 1.47.2 (AGPL-3.0). It is no longer a dependency; its historical license is retained at vendor/licenses/SuperDoc-AGPL-3.0.txt. Source repository: https://github.com/superdoc/docx-editor . The upload editor uses direct OOXML edits so original Word formatting remains intact.

The Windows PDF printing runtime is the official portable SumatraPDF 3.6.1 (64-bit), licensed under GPLv3. Source for this release: https://github.com/sumatrapdfreader/sumatrapdf/tree/3.6.1rel . License: https://github.com/sumatrapdfreader/sumatrapdf/blob/3.6.1rel/COPYING . The executable is stored under vendor/sumatra; SUMATRA_PDF_PATH can select another compatible locally installed executable.

Uploaded document contents are edited in the local browser; Office previews and printing are prepared on the shop PC. No Google Docs or Microsoft cloud account is used by this editor.
